# 设置完整性核对（SETTINGS-GAP）

- 核对日期：2026-11-08
- 核对对象：alpha9 代码库中的设置窗口（`qml/SettingsPanel.qml` + `qml/SettingsWindow.qml` + `src/window/SettingsWindow.cpp` + `src/settings/Settings.*` + `src/ui/UiStateStore.*` + `src/ui/CompactController.*`）
- 判定口径：**有**（有控件且真实生效并落配置）/ **无**（根本不存在）/ **只有入口没有功能**（控件或文案在，但点击/调整无实际效果或不落盘）/ 另：只有只读展示也记为"只有入口没有功能"（用户改不了）
- 计划来源：`MILESTONES.md` / `DESIGN.md` 在仓库中不存在（见 `docs/GAP-AUDIT.md` §0）。本清单的"计划位置"依据：①用户明确的 M2/M3 设置范围（设置、参数、偏好、快捷键、字幕、音频、播放、界面、主题、更新、存储、账户/媒体库）；②`SettingsPanel.qml` 现有六页结构；③`docs/STATE.md` 的 alpha7 §1.3 设置形态约定。**无法从原始设计稿核对，故所有结论只针对"是否真实可用/是否落盘"**。

## 0. 结论摘要

| 组 | 有 | 只有入口没有功能 | 无 |
|---|---|---|---|
| 通用/界面 | 2（主题切换、紧凑断点只读展示） | 3（断点只能手改文件、紧凑状态只读、主题无预览） | 5（语言、启动行为、关闭行为、日志级别入口、账户/媒体库入口） |
| 播放 | 1（当前播放信息只读） | 2（解码/渲染说明占位、续播无开关） | 8（硬解、缓冲、HDR、去隔行、缩放算法、自动下一集、播放速度持久化、截图） |
| 字幕 | 1（轨道列表只读） | 1（字幕预览是静态图，不反映设置） | 7（字号、颜色/描边、延迟 UI、位置/安全距、外挂加载、编码、持久化） |
| 音频 | 2（音量/静音即时生效、音轨列表只读） | 0 | 6（输出设备、声道/下混、音频延迟、音量持久化、输出后端、增益/夜间模式） |
| 快捷键 | 0 | 2（静态快捷键文本已过时、40 动作表后端有但 UI 不可见） | 4（改键、解绑、冲突提示界面、自定义键位持久化） |

## 1. 通用 / 界面（SettingsPanel 第 0 页）

| 计划位于 | 当前实际 | 差异说明 |
|---|---|---|
| 外观 → 主题选择 A/B/C | **有** | 点击 `win.action("setTheme")` → `ThemeRegistry::switchTo`，写 `ui.theme` 并存盘（`ThemeRegistry.cpp:109-111`）。但按钮只有「布局 A/B/C」文字，**没有缩略预览**，无法一眼区分控制条位置/侧栏形态/信息密度（alpha10 ②） |
| 外观 → 主题预览图 | **无** | 设置项没有任何预览控件 |
| 紧凑模式 → 断点值 | **只有入口没有功能（只读展示）** | 显示 `compactMode.breakpoint`，但无输入框/滑杆；只能手改 `settings.toml` 的 `[ui.layout.<主题>] compactBelow`，重启/切主题生效（`CompactController::loadBreakpoint`） |
| 紧凑模式 → 当前状态 | **只有入口没有功能（只读展示）** | 只显示「紧凑/常规」，用户无法手动切换 |

| 界面语言 | **无** | 全中文硬编码；无语言选择项（需求只要求中文文案，记为缺失但可延后） |
| 启动行为（恢复上次会话/自动播放/启动最大化） | **无** | 只有隐式的几何恢复（`window.*`），无任何开关 |

| 诊断日志级别 | **无界面入口** | `diag.logLevel` 键存在（默认 `info`），只能手改文件 |
| 存储位置/缓存清理 | **无** | 关于页只读展示路径，无清理/迁移入口 |
| 账户/媒体库入口 | **无** | 设置六页里没有账户或媒体库页；媒体库只有主界面空态入口 |
