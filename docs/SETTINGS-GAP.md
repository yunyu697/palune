# 设置界面完整性核对（SETTINGS-GAP）

- 核对日期：2026-11-08（Asia/Shanghai）
- 核对对象：`src/window/SettingsWindow.cpp/.h`、`qml/SettingsWindow.qml`、`qml/SettingsPanel.qml`、`qml/components/Setting*.qml`、`src/settings/Preferences.*`、`src/mpv/MpvClient.cpp`、`src/window/WindowController.cpp`、`src/ui/ActionRegistry.*`
- 当前基线：`1.0.0-alpha10` + M4 媒体库代码。**alpha9 不是当前状态**；旧版核对中的 alpha9/alpha8 结论已在本文件按当前代码重写。
- 判定列（只允许三选一）：
  - **有**：有控件，且能落到配置或即时作用于播放器/窗口
  - **无**：没有控件或整组不存在
  - **只有入口没有功能**：有控件/文案/分组，但点进去无实际效果、只读不可改、只是占位、或没有落盘
- “显式延后”不是第四种状态；凡延后项仍按其真实状态写“无/只有入口没有功能”，并在差异列写延后理由。
- **NOT_VERIFIED**：代码看得到接线，但本轮无构建、无截图、无运行取证；在读代码无法确认运行时行为时标在差异列，不能算“有”。

## 11. 结论

### 11.1 要补的整组（按组补，不东补一个西补一个）

1. **存储整组（P0）**：新增设置页/分组，包含“缓存与索引占用展示、清理可重建缓存、媒体库索引重建、配置导出/迁移”。配置键建议 `storage.*`；前两项即时，索引重建即时，迁移重启。
2. **界面语言入口（P0）**：“通用”页把静态文案替换为语言选择（跟随系统/简体中文/English），键建议 `ui.language`，默认“跟随系统”，重启或即时重建翻译均可；同时删除“只提供中文 UI”的错误文案（中英 i18n 已存在）。
3. **预览联动整组（P3，但属“改了没反应”）**：字幕预览描边宽度绑定 `sub.outline`；B 第三栏字幕预览改为绑定真实 prefs；BT.2390 曲线与“目标 nits”绑定 `playback.targetPeakNits`，不再写死。
4. **账户/媒体库入口整组（P3）**：设置页加“媒体库”分组（根目录增删、重新扫描、索引路径），或明确从 IA 中删除该入口；账户当前无后端，**显式延后并在文档写明**。
5. **设置运行时取证整组（P0）**：对 §10.2 的十项各做一次真实进程 probe/截图，补进 `docs/evidence/`；在此之前它们在复审中只能是 NOT_VERIFIED。

### 11.2 建议显式延后

| 项 | 理由 | 延后到 |
|---|---|---|
| 账户登录/云端同步 | 当前无后端、无验收项；设置页可先只留媒体库入口 | 1.1 之后 |
| 音频增益/夜间模式/均衡、输出后端 | 不在现有验收项；改 mpv 管线范围大 | 1.1 之后 |
| 字幕字体回退 | 依赖平台字体枚举，未在验收项 | 1.1 之后 |
| 播放截图/录像、缩放算法 | 未在验收项；需新增 mpv 命令与文件管理 | 1.1 之后 |
| 手动代理地址输入 | 后端 `manual:` 已支持，UI 未暴露；优先级低于用户可见缺口 | P3 批次 |
| 存储配置导出/迁移 | 属存储组内低优先项；先做占用展示 + 清理 + 索引重建 | 存储组二期 |
