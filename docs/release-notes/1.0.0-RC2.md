# Palune 1.0.0-RC2 发布说明

- 发布类型：**预发布**（`prerelease=true`，不接管 `releases/latest`）
- 平台：Windows x64（NSIS 安装包）
- 本版未提供：macOS / Linux 产物、MSI、生产签名（沿用 RC1 口径）
- 版本唯一来源：`VERSION` = `1.0.0-RC2`；安装包名、应用内「关于」与 `latest.json` 的 `payload.version` 与之逐字一致

## 一、UI 六条修复

| # | 问题 | 根因 | 改法 |
|---|---|---|---|
| 1 | 窗口按钮图标不统一 | `WindowButtons.qml` 用字符字形（`—`/`⍐`/`□`/`✕`）当图标，宽度、基线、粗细随字体回退变化，且最大化后没有还原态图形 | 改为纯矢量几何：固定 10×10 图标区、1px 描边，三按钮同尺寸同基线，最大化后换成双框（还原） |
| 2 | 标题栏与底部控制栏热区未分离 | `dragStrip` 与控制栏悬停热区高度口径混用，矮窗下叠加，按下事件被拖动层先吃掉 | `dragStrip` 按主题只占顶部（A 94 / B 52 / C 44）；控制栏改用 `HoverHandler`，只收悬停不消费点击 |
| 3 | 布局 B/C 点了不生效 | 主题卡 delegate 是 `Column`，子 `MouseArea` 用 `anchors.fill` 被 positioner 接管，命中区退化为 0×0 | delegate 改为固定尺寸 `Item` + 铺满整卡的兄弟 `MouseArea`，补 hover/光标/ToolTip；名称改为「A · 经典 / B · 工作台 / C · 沉浸」 |
| 4 | 滚动条遮挡内容 | 内容列宽取 `Flickable.width`，8px 悬浮滚动条压在内容右缘 | 内容列宽减 12px，滚动条独占右侧；`ScrollBar.vertical.width` 显式声明 |
| 5 | 「打开主页」指向不存在的站点 | 写死 `https://palune.app/`，该域名无服务（TLS 握手失败） | 改为本仓公开地址 `https://github.com/yunyu697/palune` |
| 6 | 设置窗口不是真正独立窗口 | `Qt::Tool` + `setTransientParent` + 主窗几何四连跟随，设置窗随主窗移动/缩放/最小化 | 改为 `Qt::Window | FramelessWindowHint | NoDropShadowWindowHint`，去掉瞬态父窗与四条跟随连接，只在显示时居中一次 |

逐条证据（真实点击/拖动探针、截图、原始 JSON）：`docs/evidence/rc-ui-fixes.md`、`docs/evidence/rc-ui-probe.json`。

## 二、覆盖窗与视频窗分层

- 新增 `enforceLayering()`：用 `SetWindowPos(videoHwnd, overlayHwnd, … SWP_NOACTIVATE)` 显式把视频窗钉在覆盖窗正上方，修正暂停/切主题/被其他窗口遮挡后出现的 z 序错位与残影。
- 触发点：400ms 看门狗定时器 + 覆盖窗 `nativeStateChanged` + 换屏（`screenChanged`，同时重同步几何并刷新暂停帧）。
- 证据：`qa/evidence/layering/FINDINGS.md` —— 独立隐藏桌面上测 covered-switchback / pause-resume / theme-cycle 三格，结构判据 0/3 异常、渲染连续性 0/3 差异 >15%；最小化恢复、全屏往返等 7 格因独立桌面无合成器驱动，**未验证**，不计入通过。

## 四、圆角白边与圆角不一致

1. **删除 QML 自绘的窗口发丝描边**（`#1affffff`，1px，`radius: windowRadius - 0.5`）——深色界面四边/四角那圈浅白边的直接来源。离屏像素剖面：左上角 3px 边缘带亮像素 726/1206 → **0/1206**，对角线剖面由「13×8, 20, 37, 13×10」变为全平。
2. **窗口圆角收敛为单一来源**：`ThemeRegistry::windowRadius` A=14/B=10/C=20 → **12/8/18**（落在令牌阶梯内）；`SettingsWindow` 删除自带的 B?8:18 第二张表，改为引用同一函数；`SettingsWindow.qml` 的裸值回退改为 `tokens.radiusL`。
3. **系统窗框交给系统画**：新增 `src/window/SystemChrome.h`，一次性下发 `DWMWA_WINDOW_CORNER_PREFERENCE` + `DWMWA_USE_IMMERSIVE_DARK_MODE` + `DWMWA_BORDER_COLOR`；全屏/最大化时改为 `DWMWCP_DONOTROUND`。主题切换时由 QML 下发 `tokens.layerSolid` 作为边框色。
4. **拦回归**：`tools/ci/check_design_tokens.py` 新增 D8/D9/D10（窗口圆角必须来自令牌阶梯、设置窗不得另起表、同一组件不得并存两档、窗口圆角不得做偏移），已接入 CI 与出包流程。当前全仓 61 处 `radius:` 全为 `tokens.radius*` 或几何推导，0 处裸值。

未验证（不写成已修复）：Win11 真机四角 DWM 合成、暗色模式与边框色是否彻底消除系统亮边、透明窗 Region 抗锯齿观感、双顶层窗逐像素对齐、设置窗作为独立窗口的四角、macOS 窗口圆角、Win10 无系统圆角回退、最大化/全屏往返后的角部、125%/150% DPI。清单见 `qa/evidence/radius/FINDINGS.md` §6。

## 五、依赖部署与 CI 校验（出包门禁）

1. **构建树依赖完整性**：`tools/ci/check_exe_deps.py` 解析每个 exe 的 PE 导入表（含延迟导入）并递归检查同目录 DLL；CI 对 `build/Release` 下 12 个可执行文件执行，**12/12 通过**。
2. **安装暂存树依赖完整性**：`cmake --install` 后的暂存树同样跑一遍 check_exe_deps，并加白名单（`Palune.exe`、Qt DLL、`platforms/qwindows.dll`、`qt.conf`、`libmpv-2.dll`、`libsodium.dll`、`vcruntime140.dll`、`msvcp140.dll`、`qml/QtQuick/qmldir`）；缺任何一件**拒绝出包**，不再等用户双击看到「Qt 平台插件初始化失败」的系统弹框。
3. **运行时部署统一入口**：新增 `cmake/deploy_qt_runtime.cmake`，Qt DLL / 平台插件 / CRT / `qt.conf` 由同一处部署，构建树与安装树口径一致。
4. **CI 门禁**：qmllint（`--qml-check` 同时加载 qrc 内全部 QML）、设计令牌检查、i18n/硬编码文本检查、安装器自检（`qt.conf`、CRT、`--version` 真启动一次）全部前置到出包之前。

## 六、其他随版内容

- 播放队列 `PlayQueue`（追加/保存/载入 `.json` 队列）与拖放统一入口（媒体 / 字幕 / 网络地址，多文件入队）。
- 打开网络地址（http/https/rtsp/rtmp 等直接交给 mpv）。
- 新增 `--qml-check`（QML 全量加载自检）与 `--p0-probe`（真实 libmpv 下章节/比例/字幕样式/截图回读）两个自检开关。

## 升级

- 覆盖安装即可；已安装 `1.0.0-RC1` 的用户直接安装本版。
- 校验方式：`SHA256SUMS` 对安装包做 SHA-256；`latest.json` 用 `resources/trust/update.pub` 做 Ed25519 验签。
