# 鼠标与键盘交互定义（alpha10 起生效）

> 目的：消除"点一下不知道会发生什么"。本文件是唯一口径，实机复验按此执行。
> 实现位置：`qml/Main.qml`（视频区）、`qml/layouts/*`（控制条）、`qml/components/*`、`src/window/WindowController.cpp`（动作分发）。

## 1. 区域划分

| 区域 | 范围 | 说明 |
|---|---|---|
| 标题/拖拽区 | 窗口顶部：A 94px、B 52px、C 44px（`Main.qml` `dragStripHeight`） | 无边框窗口的"标题栏"；空白处可拖动 |
| 视频内容区 | 除控制栏、侧栏、标题区之外的整个客户区 | 单击/双击/右键/滚轮都在这里生效 |
| 控制栏区 | 窗口底部整条区域：A = 控制条高度 + 10px；B = 82px；C = 胶囊高度 + 24px（紧凑时各自降级） | **包含控制条隐藏时的同一条区域**，是悬停热区 |
| 面板区 | 媒体库侧栏 / 检查器 / 设置窗 | 有自己的鼠标处理，点击不落到视频区 |
| 窗口边缘 | 四边与四角 8px（`WindowController` 的 resize 热区） | 拖动改窗口大小 |
| 空态区 | 无文件时的 EmptyState | 单击视频区无效；打开/媒体库/设置按钮负责动作 |

## 2. 鼠标定义

| 输入 | 区域 | 行为 | 例外 |
|---|---|---|---|
| 左键单击 | 视频内容区 | **播放 / 暂停** | 无文件时空操作；面板打开时不生效 |
| 左键双击 | 视频内容区 | **全屏 / 退出全屏** | 无文件时无效 |
| 右键单击 | 视频内容区 | **弹出上下文菜单**（播放/暂停、全屏/还原、打开文件、媒体库、设置、退出） | 无文件时不弹 |
| 滚轮 | 视频内容区 | **音量 ±5%**（每格 120 delta 计 5%） | — |
| Ctrl + 滚轮 | 视频内容区 | **快进/快退 ±10 秒** | — |
| 左键按下并移动 | 标题/拖拽区 | 系统移动（`startSystemMove`），保留 Aero Snap | 按钮/控件优先 |
| 左键双击 | 标题/拖拽区（主窗） | 最大化 / 还原 | 设置窗为固定尺寸对话框，**不做双击最大化**（会破坏跟随主窗的定位规则） |
| 左键拖动 | 窗口四边/四角 8px | 系统缩放（`startSystemResize`） | 最大化/全屏时禁用 |
| 左键点击 | 控制条任意控件 | 执行控件动作，**不穿透到视频区** | 控制条位于 layoutSlot 之上 |
| 左键拖动 | 进度条轨道 | seek（拖动期间不触发播放/暂停） | — |
| 悬停进入 | 控制栏区（整条，含隐藏态） | **立即显示控制栏** | 无文件时不显示 |
| 悬停离开 | 控制栏区 | **2500ms 后隐藏控制栏**（仅播放中） | 暂停时不自动隐藏；面板打开时不隐藏 |

## 3. 实现要点与根因对应

1. **单击不再切换控件显示**。alpha9 及以前：`Main.qml` 全窗 `MouseArea` 的 `onClicked` 是 `uiState.chromeVisible = !uiState.chromeVisible`，导致"点一下视频控件消失、布局 B 右栏跟着消失"。现改为 `win.action("playPause")`。
2. **控制条热区用 `HoverHandler`**，不用 `MouseArea`：`HoverHandler` 只接收悬停、不消费点击，因此控制条隐藏时该区域不会拦住视频区的单击/双击。
3. **控制栏显示/隐藏只有一个入口**：`uiState.chromeVisible`。手动切换仍可通过 `toggleChrome` 动作（快捷键），但鼠标单击不再触发。
4. **自动隐藏计时器**：`Main.qml` `chromeHideTimer`，2500ms；触发条件为"有文件 + 未暂停 + 鼠标不在热区 + 没有打开面板"。
5. **右键菜单**：`Main.qml` `Menu`，动作全部走 `win.action(...)`，与快捷键共用同一分发。
